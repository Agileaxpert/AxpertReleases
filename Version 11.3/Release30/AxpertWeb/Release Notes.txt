  Action: 1. Verify the IIS configuration:

     c. Confirm that the website bindings point to the application site and not the IIS Default Web Site.
  2. Verify infrastructure configuration:
     a. Check the load balancer configuration and ensure all backend servers are serving the application instead of the IIS default page.
     b. Verify that the SSL certificate is correctly bound to the application website.
     c. Confirm that no backend server exposes the IIS Welcome Page.

  b. Verify that the application is accessible only over HTTPS and that HTTP requests are redirected to HTTPS.
